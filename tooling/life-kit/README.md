# life-kit

Skills and agents for working in the Life network, ready to use with an instance: the development
cycle (`dev-workflow`, `rpit-loop`, `autoloop`, `testing`), git and issues (`git-workflow`,
`github-issues`, `next`, `chiudi-task`), knowledge in the instance brain (`idea`, `idee-revisione`),
decisions (`consiglio`, `prior-art-redteam`), autonomous work (`lavoro-notturno`), indexes for
third-party plugins (`indice-*`), and the `esplora`, `pianifica`, `revisione-codice`, `sicurezza`,
`test`, and `docs` agents.

Install from the Life marketplace:

```bash
claude plugin marketplace add $SRV_ROOT/Life
claude plugin install life-kit@life
```

Or install it with all third-party plugins using `bash scripts/kit/installa-strumenti.sh`.

**Do not edit by hand.** The content is generated by `scripts/kit/esporta-kit.py` from the suite's
tools: `kit.json` defines what is included and which substitutions to apply; `overrides/` contains
manually written generic versions, and every file passes the privacy gate (`lifegate`) before
inclusion. `kit.lock.json` records the source version for each entry; `esporta-kit.py --check`
reports which entries have changed.
